# LAND BATTLE LIVE — MVP

TikTok LIVE үзэгчид Follow / Like / Gift-ээр оролцдог, дугуй аренд бөмбөлгөө томруулж бусдаа шахаж гаргадаг физик тоглоом.

```
land-battle/
├── index.html      тоглоом + туршилтын самбар
├── game.js         физик, раунд, 3 амь, оноо, ranking, рендер, bridge client
├── audio.js        дууны эффект, хөгжим, AI тайлбарлагч (бүгд WebAudio-оор нийлэгжүүлсэн)
├── style.css
└── bridge/         TikTok LIVE → WebSocket bridge (Node.js)
    ├── server.js
    └── package.json
```

## 1. TikTok-гүйгээр турших (симуляц)

`land-battle/index.html`-ийг браузерт нээнэ (эсвэл сайт дээр `/land-battle/`).

* Баруун самбар: Follow, Like, Rose, жижиг/том Gift, Comment товчлуурууд
* **+10 бот** ба **Авто симуляц** — 10–30 тоглогчийн ачааллыг шалгах
* `?demo=1` — ботууд + авто симуляцтай шууд эхэлнэ
* `?overlay=1` — самбаргүй, зөвхөн 9:16 дэлгэц (OBS / TikTok LIVE Studio)
* `?safe=1` — TikTok-ийн UI дарах бүсийг (дээд/доод) улаанаар харуулна
* `?voice=off|browser|azure` — тайлбарлагчийн горим
* `H` товч — самбар нуух/харуулах

## 2. TikTok LIVE-тэй холбох

### Windows: `start.bat` (хамгийн хялбар)

1. [Node.js LTS](https://nodejs.org/) суулгана (байхгүй бол `start.bat` өөрөө татах хуудсыг нээнэ).
2. TikTok дээр **LIVE эхлүүлнэ**.
3. `land-battle\start.bat` дээр давхар дарна → **[1]** → анх удаа TikTok нэрээ бичнэ (хадгалагдана).
4. Браузер автоматаар нээгдэнэ. OBS / LIVE Studio-д оруулах хаяг хар цонхонд бичигдсэн байна.
5. LIVE дуустал хар цонхыг бүү хаа.

LIVE Studio / OBS-д тоглоомыг барихдаа **`overlay.bat`**-ийг ажиллуулна: тусдаа босоо Edge цонх нээгдэх бөгөөд
цонх ард далдлагдсан ч тоглоом зогсохгүй, дуу автоматаар асна. Тэр цонхыг **Window capture**-аар барина.

Цэс: [2] TikTok-гүй туршилт · [3] нэр солих · [4] Azure монгол хоолойн түлхүүр.
Эхний удаа шаардлагатай сангуудыг (`npm install`) өөрөө суулгана.

### Гараар (Mac / Linux / Windows)

```bash
cd land-battle/bridge
npm install
node server.js --user=@таны_tiktok_нэр      # LIVE эхлүүлсэн байх ёстой
# эсвэл TikTok-гүй хуурамч event:  node server.js --mock
```

Дараа нь `http://localhost:8787/?ws=auto` нээнэ (bridge тоглоомыг өөрөө serve хийнэ).
LIVE Studio / OBS-д Browser Source болгон `http://localhost:8787/?ws=auto&overlay=1` (1080×1920) нэмнэ.

> ⚠ **Анхааруулга:** bridge нь `tiktok-live-connector` гэх **албан бус** community сан ашигладаг
> (TikTok-ийн нийтэд нээлттэй LIVE webcast-ийг уншдаг). Энэ нь TikTok-ийн албан ёсны API биш.
> Production-д ашиглахаас өмнө TikTok-ийн үйлчилгээний нөхцөл болон албан ёсны LIVE developer
> хөтөлбөрийн боломжийг шалгана уу. Эх үүсвэр нь `server.js` доторх `createTikTokSource()`-д
> тусгаарлагдсан тул зөвшөөрөгдсөн өөр provider-ээр солиход хялбар.

## 3. Тоглоомын дүрэм (одоогийн хэрэгжилт)

| TikTok үйлдэл | Нөлөө |
|---|---|
| Follow | Тоглоомд нэгдэнэ (өмнө нь follow хийсэн хүн Like/Comment `!join`-оор автоматаар нэгдэнэ) |
| Like | Like бүр +1 оноо → бөмбөлөг томорно. Хэрэглэгч бүрт token bucket (10/сек, burst 40) |
| Rose (1💎) | +20 bonus оноо. Хасагдсан эсвэл хоцорсон тоглогч Rose-оор **тулаанд шууд орно** (1 амьтай) |
| Жижиг gift (≤99💎) | 💎 × 4 оноо + 15 сек Like ×2 өсөлтийн boost (ногоон цагираг) |
| Том gift (≥100💎) | 💎 × 4 оноо + boost + 12 сек түлхэх хүч ×2.2, health дүүрнэ (алтан цагираг) |
| Comment | Feed-д гарна. `!join` — нэгдэх, `!stats` — өөрийн rank/оноо |

**Бөмбөлгийн үзүүлэлт:** Size (оноо → талбай), Mass = r², Push Force (хэмжээ + power-up),
Speed (жижиг нь хурдан), Health (захад байхад багасаж, барьц сулардаг), Score.

**Battle:** тоглогч бүр **3 амьтай** (❤❤❤ бөмбөлгийн доор). Зах руу шахагдвал (төв нь шугамаас гарвал) 1 амь хасагдаж,
төв рүү 60% хэмжээтэй, 2 сек хамгаалалттай буцаж гарна. 3 амь дуусвал хасагдана. Шахсан тоглогч оноо авна.
40 секундээс хойш арен аажмаар багасна. Нэг л тоглогч үлдэх, эсвэл 150 сек дуусахад хамгийн том нь ялна.

**Раунд:** Lobby (12 сек, хамгийн багадаа 2 тоглогч) → Battle → Ялагчийн animation (7 сек) → шинэ раунд автоматаар.
Battle эхэлснээс хойш 25 секундын дотор шинээр нэгдэх, ялагдсан нь Like/Gift-ээр буцаж орох боломжтой
(хагас хэмжээтэй). Түүнээс хойш дараагийн раундын дараалалд орно. 10 минут идэвхгүй тоглогч дараагийн раундад автоматаар орохгүй.

**Ranking (TOP 10):** нийт оноо + амьд бол одоогийн хэмжээ. 1–3 байр алт/мөнгө/хүрэл.

Бүх тоо самбарын **Баланс тохиргоо** хэсгээс өөрчлөгдөж, браузерт хадгалагдана.

## 4. Дэлгэцийн зохион байгуулалт (TikTok-д тааруулсан)

* **y 0–140** — TikTok хөтлөгчийн мэдээлэл: юу ч зурахгүй
* **Гарчиг + "Хэрхэн тоглох" 4 карт** (Follow / Like / Rose / Gift) — үргэлж харагдана, тухайн үйлдэл болоход гэрэлтэнэ
* **Төлөв:** цаг, үлдсэн тоглогч, нэгдэх хугацаа
* **Арен (зүүн)** + **Шилдэг 10, Шилдэг дэмжигч, event жагсаалт (баруун)**
* **y 1300–1920** — TikTok comment, gift товч: хоосон үлдээсэн
* Голд том мэдэгдэл: тулаан эхлэх, том gift, хасагдах, "Сүүлийн 3!", арен багасах

## 5. Дуу ба AI тайлбарлагч

* **Эффект:** нэгдэх, like, мөргөлдөх, rose, gift, том gift, амь алдах, хасагдах, тоолох, эхлэх, сэрэмжлүүлэг, ялалт.
  Файлгүй — WebAudio-оор нийлэгжүүлдэг. Хөгжим тулааны үед хурдсаж, арен багасахад илүү эрчимтэй болно.
* **Тайлбарлагч** тоглоомын үйл явдлыг монголоор хэлнэ (нэгдэх, gift, шахалт, тэргүүлэгч солигдох, сүүлийн 3, ялагч …).
  Ярих үед хөгжим/эффект автоматаар намсна. Хуучирсан (6 сек+) өгүүлбэрийг алгасна. "Ярих давтамж"-аар тохируулна.
  * **Браузер TTS** — үнэгүй, гэхдээ ихэнх Windows/Chrome-д монгол хоолой байхгүй тул орос/англи хоолойгоор уншина.
  * **Azure монгол хоолой (зөвлөмж)** — `mn-MN-BataaNeural` (эрэгтэй) / `mn-MN-YesuiNeural` (эмэгтэй):
    ```bash
    AZURE_SPEECH_KEY=xxxx AZURE_SPEECH_REGION=eastasia node server.js --user=@нэр
    # хоолой солих: AZURE_VOICE=mn-MN-YesuiNeural
    ```
    Тоглоомыг bridge-ээр (`http://localhost:8787/?ws=auto&voice=azure`) нээнэ. Давтагдах өгүүлбэр cache-д хадгалагдана.
* **Өөрийн хоолой (хамгийн бодит):** самбарын **🎙 Өөрийн хоолой** хэсэгт 16 өгүүлбэрийг микрофоноор бичнэ
  (● Бичих → хэлэх → ■ Зогсоох). Эхэн/төгсгөлийн чимээгүйг автоматаар тайрч, чанга сулыг тэнцүүлнэ.
  Нэг өгүүлбэрт 2–3 хувилбар бичвэл ээлжлэн тоглоно. Бичлэгүүд `bridge/voices/`-д хадгалагдана (OBS-д ч сонсогдоно).
  Тэнд өөрийн mp3/wav файлыг `start_1.mp3`, `final3_2.wav` гэх мэтээр нэрлэж хийж болно.
  Бичээгүй өгүүлбэрт TTS ажиллана; TTS-ийг "Унтраах" болговол зөвхөн таны хоолой сонсогдоно.
* **Браузерт** дуу асаахын тулд нэг удаа дарах шаардлагатай (autoplay хязгаарлалт). OBS-ийн Browser Source-д
  "Control audio via OBS"-г асааж стрим рүү дууг дамжуулна.

## 6. Найдвартай байдал

* **Like flood:** bridge 250мс тутамд хэрэглэгч бүрийн like-ийг нэгтгэнэ + тоглоом дотор token bucket.
* **Gift streak:** давтагдах gift-ийн `repeatCount`-ийн зөрүүг л тоолно (давхар тоолохгүй).
* **Dedupe:** `msgId`-аар давхардсан event хасна.
* **Reconnect:** TikTok холболт тасрахад bridge 5→60 сек backoff-оор дахин холбогдоно;
  браузер bridge-ээс тасрахад 1.5→30 сек backoff.
* **Event recovery:** event бүр `seq` дугаартай, сүүлийн 2000 нь bridge-д хадгалагдана.
  Браузер дахин холбогдохдоо `lastSeq` илгээж алдсан event-үүдээ авна. Bridge restart хийвэл `boot` ID-аар илрүүлж seq-ээ шинэчилнэ.

## 7. Дараагийн алхам

* Жинхэнэ LIVE дээр баланс тааруулах (like-ийн тоо стримээс хамаарч их зөрнө)
* Нийт оноо браузерийн localStorage-д хадгалагддаг (refresh хийхэд үлдэнэ). Олон төхөөрөмж хооронд хуваалцах бол сервер талд хадгалах
* Gift бүрт тусгай animation
* Comment командаар чиглэл өгөх (`!left`, `!dash` гэх мэт)

# 🐎 МОРИН УРАЛДААН (`race.html`)

Наадмын хурдан морины уралдаан: үзэгчид comment-оор морь сонгож, like/gift-ээр давхиулна.

**Нэг уралдаан:**
1. **🗳 Санал авалт (25с)** — дэлгэц дээр том "САНАЛ ӨГ!" гарч, хоолой зарлана. Comment-д **1–6** бичиж морь сонгоно (нэг удаа).
2. **🚩 Гийнгоо + 3-2-1** — морьд гараанд.
3. **🏇 Уралдаан (~50с)** — дээрээс харсан тал нутаг, км тэмдэг, барианы шугам.
   * ❤ **Like** = дэмжсэн морь хурдлана · 💬 comment = бага зэрэг хурдлана
   * 🌹 **Rose** / 🎁 **Gift** = морь **хүчтэй давхина** (доорх хүснэгт)
   * Gift илгээгээд санал өгөөгүй бол хамгийн цөөн дэмжигчтэй морийг автоматаар дэмжинэ
4. **🏆 Дүн** — түрүү морь, **айргийн тав**, **бүүрэг**, хэдэн хүн зөв таасан. Морь бүрийн хамгийн их дэмжсэн хүн = **уяач**.

**Gift = хүчтэй давхилт** (газраар, бодит наадам шиг — тоос, хурдны зураас, том gift-д алтан гэрэл):
| Gift | Нэр | Үйлдэл |
|---|---|---|
| 🌹 Rose | **Гийнгоо** | 1.6с хурдална |
| 🎁 < 100💎 | **Давхилаа** | 3.5с хүчтэй давхина |
| 💎 100–999💎 | **Хийморь сэргэлээ** | 6с маш хурдан, алтан гэрэл |
| ⚡ 1000💎+ | **Аянга шиг давхилаа** | 9с, дэлгэц гялбана |

**"Юу болох бол?" — гэнэтийн зүйлс:**
* 🌊 **Гол** — бүх морь удааширна, **gift-ээр давхиж буй морь хурдан гатална** (тайлбарлагч урьдчилан анхааруулна)
* 🟫 **Шавар** — тухайн эгнээний морийг удаашруулна
* ❓ **Нууц хайрцаг** — хурд / давхилт / толгой эргэх / дэмжигчдэд +20 оноо. Ойртоход "Юу болох бол?" гарна
* 😱 **Бүдрэх** (тэргүүлэгч 3-ын нэг) · 🔥 **Гүйцэж ирэх** (хамгийн сүүлийн морь гэнэт хурдална)
* 📸 **Фото финиш** — эхний 2 морь ойрхон бол удаашруулсан дүрс
* 🔥 Дараалан таасан хүнийг нэрээр нь дуудна

**6 нас = 6 уралдаан:** Даага (12км) → Шүдлэн → Хязаалан → Соёолон → Их нас → Азарга. Дараа нь
**"Наадам өндөрлөлөө"** — шилдэг 8 уяач (оноогоор), дахин эхэлнэ.

**Оноо:** таны морь 1-р байр +100, 2-р +60, 3-р +40, 4-р +25, 5-р +15, санал өгсөн +5, уяач +30.

**Ажиллуулах:** `start.bat` → **[1] МОРИН УРАЛДААН** (LIVE) эсвэл **[3]** (туршилт).
LIVE Studio-д: **`overlay-uraldaan.bat`** → Window capture.
Өөрийн хоолойгоор бичих 10 өгүүлбэр (гийнгоо, түрүүлэх, бүүрэг …) самбарын **🎙 Өөрийн хоолой** хэсэгт бий.

**Үзэгч өөрийгөө харна:** like/comment/gift бүрт тухайн хүний зураг + нэр ("bataa ❤×15") морины хажууд гарна;
хамгийн их дэмжсэн 5 хүний зураг морины араас дагаж давхина.
**Адуун сүрэг:** 12 нэртэй морь (Аянгын Хүрэн, Хар Шонхор …) уралдаан бүрт эргэж ирж, түрүү/айраг/бүүрэгийн түүхтэй болно.
**Цол:** нийт оноогоор Уяач → Алдарт уяач (300) → Аймгийн алдарт уяач (1500) → Улсын алдарт уяач (5000).
**7 хоногийн аварга:** оноо bridge-ийн `bridge/data/store.json`-д хадгалагдана.

# 🐑 Хандивын зорилго (`goal.html`)

Rose болон бусад бүх gift **"МАЛЧИН тоглоомыг гаргая!"** зорилгын bar-ыг дүүргэнэ. Bar нь бүх тоглоомын
дээд хэсэгт (гарчгийн оронд) харагдана; 25 / 50 / 75 / 100%-д хүрэхэд тайлбарлагч зарлана.

* Gift-ийг **bridge** тоолдог тул олон цонх нээлттэй байсан ч давхардахгүй, LIVE хооронд хуримтлагдана (`bridge/data/store.json`).
* **Хандивын хана:** `http://localhost:8787/goal.html` (самбар дээрх 🐑 холбоос) — бүх дэмжигчийн нэр/зураг, зорилгын тохиргоо
  (гарчиг, тайлбар, хэдэн 💎), **CSV татах** (Малчин тоглоомын credits-д оруулах нэрс: нэр, @TikTok, алмаз, огноо), туршилт, тэглэх.
* LIVE Studio-д хана хуудсыг `goal.html?overlay=1` гэж тусдаа цонхоор барьж болно.
* Туршилтын (mock) горимын gift тусдаа тоологдож, хадгалагдахгүй.

**Гүйдэг нэрс ба танилцуулга:** тоглоомын дээд талын bar-ын гарчиг 10 секунд тутам "🐑 Нэр нь МАЛЧИН-д мөнхлөгдөх: …"
гүйдэг мөрөөр солигдоно. Раунд хооронд (анхдагч 240 секунд тутам) ~15 секундын **"МАЛЧИН — тоглоомын тухай"** дэлгэц гарч,
тайлбарлагч танилцуулгыг уншина, дэмжигчдийн нэр кино шиг дээшээ гүйнэ. Тоглоомын нэр, танилцуулгын мөрүүд, давтамжийг

# 🐑 СҮРГЭЭ АВАР (`herd.html`)

Асуулт хариултын шинэ горим (оноо = үнэгүй хонь, мөнгө биш):
* Тоглогч бүр **1000 хонь**той эхэлнэ (эхний 3 асуултын дотор нэгдэнэ).
* **Сэдэв сонгох:** хоёр сэдэв гарна — comment-д **1** эсвэл **2** (олонх нь шийднэ; 1000💎+ gift илгээгч өөрөө сонгож болно).
* **Хонио хуваах:** `2` → бүх хонь 2-т · `1 60 3 40` (эсвэл `1-60, 3-40%`) → 60% 1-д, 40% 3-т.
  Хамгийн ихдээ 3 хашаанд, хугацаа (30с) дуустал өөрчилж болно. Хашаа бүрт нийт хэдэн хонь, хэдэн хүн байгаа шууд харагдана.
* **Хариу:** буруу хашаанд 🐺 чоно орж хонийг хөөнө — зөвхөн зөв хашааны хонь үлдэнэ. Хариулаагүй бол сүргийн тал нь тарна.
  Хонио бүгдийг алдвал тухайн тоглолтоос хасагдана.
* 8 асуултын эцэст **хамгийн том сүрэгтэй** нь ялна; 7 хоногийн аварга тусдаа.
* ❤ Like / 🌹 Rose / 🎁 Gift — хонь нэмэхгүй, бүх хүнд тусална (хашаа хаах, +5с).
* `start.bat` → **[3]**, LIVE Studio-д **`overlay-sureg.bat`**.

# 💰 МӨНГӨӨ ХАДГАЛ (`money.html`)

"Сүргээ авар"-тай ижил дүрэмтэй, **мөнгөний шоуны** дүр төрхтэй хувилбар: улаан-алтан студи, гэрлийн туяа,
өөрийн зурсан ногоон **₮ боодлууд** (жинхэнэ дэвсгэртийн загвар биш), буруу хариултын мөнгө 🔥 **шатна**.
Тоглогч бүр **1 сая₮ виртуал мөнгө**тэй эхэлнэ — дэлгэц дээр үргэлж "Виртуал мөнгө — тоглоомын оноо, жинхэнэ шагнал биш"
гэж бичигдэнэ. Жинхэнэ мөнгөн шагнал амлахгүй байх нь TikTok-ийн дүрэмд нийцнэ.
`start.bat` → **[4]**, LIVE Studio-д **`overlay-mungu.bat`**.

**Шинэчлэл (сүрэг/мөнгө):** хамтын like-ийн bar хасагдаж, оронд нь **🏆 Шилдэг тоглогчид** (хамгийн их мөнгө/хоньтой 6 хүн) шууд харагдана.
Like тоглоомд нөлөөлөхгүй; 🌹 Rose = илгээгчийн нэр гарна, 🎁 Gift = бүгдэд +5 сек, 💎 100+ = нэг буруу хариулт хаагдана.
Мөнгөний горимд мөнгө унаж дуустал жагсаалт, дүн хуучнаараа үлдэнэ (хариуг урьдчилж мэдэгдүүлэхгүй).

**Gift (сүрэг/мөнгө):** тоглоомд огт нөлөөлөхгүй — зөвхөн **МАЛЧИН-д хөрөнгө оруулалт** болж зорилгын bar-д орно,
илгээгчид баярлалаа гэж зарлаж, нэр нь хандивын жагсаалтад (credits) бүртгэгдэнэ. Тоглоомыг зөвхөн мэдлэгээр хождог.

**Мөнгөний систем (Мөнгөө хадгал):** хүн бүр **50 сая₮ = 50 боодол** (1 боодол = 1 сая₮) виртуал мөнгөтэй эхэлнэ.
Comment-д бичсэн хувиар **бүхэл боодлоор** хуваагдана (`1 60 3 40` → 1-д 30 боодол, 3-т 20 боодол); 4 хариултын 1-ийг заавал хоосон үлдээнэ.
Comment бичихэд "✅ bataa ➜ 1: 30 сая₮ · 3: 20 сая₮" гэж батлагдана; `мөнгө` гэж бичвэл үлдэгдэл харагдана;
хариуны дараа бүх хүний "50 сая → 30 сая" гүйдэг мөрөөр гарна.

**Асуултын сан ба хүндрэл:** `questions.js`-д 206 асуулт, тус бүр `d: 1…5` хүндрэлтэй. Тоглолт амархнаас эхэлж
сүүлдээ маш хэцүү болно (8 асуулт: 1,1,2,2,3,3,4,5). Асуултын карт дээр ангилал + түвшин ("Соёл · Амархан") харагдана.

**Мөнгөө хадгал — НЭГ БАГ:** бүх үзэгч нэг баг; баг **50 сая₮ (50 боодол)**-той эхэлнэ. Хүн бүр comment-д саналаа бичнэ
(`2` эсвэл `1 60 3 40`); **бүх саналын дунджаар** багийн мөнгө авдруудад бүхэл боодлоор байрлана (хамгийн ихдээ 3 авдар, 1 нь хоосон).
Буруу авдрын мөнгө унаж, зөв авдрын мөнгө дараагийн асуултад үлдэнэ; 0 болбол тоглолт дуусна.
Хүн бүр өөрийн саналаараа оноо авна (зөв хариултад тавьсан хувь = оноо) — **🏆 Шилдэг тоглогчид** үүгээр эрэмбэлэгдэнэ.
`мөнгө` гэж бичвэл багийн мөнгө харагдана.

**Шат ба харамсал:** төлөвийн мөрийн доор шатны зам (★ 50 сая → ① 40 сая → ② 8 сая → …) харагдана; шат бүрийн төгсгөлд
"2-р шат: 22 сая₮ үлдлээ · −28 сая унав" гэж зарлана. Мөнгөний тэнцээс илүүг алдвал "өө…" дуу, гунигтай мэдэгдэл;
бүгдийг алдвал дэлгэц саарал болж бороо орно, "вааа-ваа-ваа" бүрээ, "Өө… харамсалтай" — төгсгөлд мөнгө хэрхэн буурсныг харуулна.
